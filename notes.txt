## Sometimes its needed to fix the project TOML:

python -c "from pathlib import Path; p=Path('pyproject.toml'); b=p.read_bytes(); p.write_bytes(b[3:] if b.startswith(b'\xef\xbb\xbf') else b); print('fixed', p)"

## If more files have the same problem: 

python -c "from pathlib import Path; exts={'.py','.toml','.md','.yaml','.yml','.txt','.ps1'}; fixed=[]; 
for p in Path('.').rglob('*'):
    if p.is_file() and p.suffix.lower() in exts:
        b=p.read_bytes()
        if b.startswith(b'\xef\xbb\xbf'):
            p.write_bytes(b[3:])
            fixed.append(str(p))
print('Removed BOM from', len(fixed), 'file(s)'); print('\n'.join(fixed))"

## Useful graphab 2.8 detail

For later HPC work, Graphab 2.8 supports -proc n to use multiple cores on one computer, and the docs specifically mention that for a single machine. That belongs in a future config parameter, but I would leave it off for this first baseline test.
