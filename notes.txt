
Create venv and activate

python -m venv .venv (ignore if already created)
.venv\Scripts\Activate.ps1

Install habconn locally and editable

pip install -e .

Install necessary packages

pip install geopandas rasterio pandas numpy shapely

Check java (needs version 11 or newer)

java -version

(in w. powershell you must use & to execute a quoted path: 
& "C:\Program Files\Java\jdk-17\bin\java.exe" -version)

If that works → good

Then confirm:

Get-ChildItem tools

You should see:

graphab.jar

If not, copy it there. IMPORTANT NOTE: I always change the file to graphab.jar to not change it in the path each new version.

Only reinstall locally if:
change things like:
pyproject.toml
dependencies
package metadata

One more useful 2.8 detail

For later HPC work, Graphab 2.8 supports -proc n to use multiple cores on one computer, and the docs specifically mention that for a single machine. That belongs in a future config parameter, but I would leave it off for this first baseline test.
